Polytope is the design system this site is built with. It ships as plain CSS, Astro components, and a Python theme for matplotlib, plotly, Gradio, and Streamlit, all generated from a single token file, so the figures in a paper match the page that hosts them.

It includes components for paper pages (headers, abstracts, citations, BibTeX, theorem environments), a publication list, site search over a static index, and three interactive models: a Vietoris-Rips complex, a Galton board, and a globe that follows a CV.
