Most graph benchmarks describe a molecule as atoms joined by bonds. Chemists, however, reason about rings, functional groups, and other substructures that involve several atoms at once. Topological Deep Learning (TDL) builds neural networks for such higher-order relations, using hypergraphs, simplicial complexes, and cell complexes, yet the community has been evaluating these models on a handful of datasets (Papamarkou et al., 2024). When every new architecture is compared on the same few benchmarks, it is hard to tell whether an idea generalizes. The 2025 challenge, run at the first Topology, Algebra, and Geometry in Data Science (TAG-DS) conference, treated this as a data problem and asked the community to contribute to TopoBench, an open-source library for benchmarking topological neural networks.

This page is a companion to the report. It explains how the challenge was organized, what kinds of datasets it brought in, and why the results matter for anyone searching for TopoBench datasets, higher-order graph datasets, or hypergraph benchmarks.

## How the challenge worked

Anyone could take part by opening a pull request against TopoBench. Each request had to pass the repository tests and add at most one dataset loader, so every contribution arrived as reviewable, runnable code. The organizers split the work into two missions. Mission A asked for dataset loaders, in two flavors: well-established graph and point cloud datasets (Category A.1), which connect TDL to mainstream graph learning, and datasets where higher-order structure is native to the data (Category A.2), such as hypergraphs and simplicial complexes. Mission B asked for infrastructure: loaders that read from disk so that large datasets avoid the memory cost of lifting to a higher-order domain (Category B.1), and new benchmark tasks, e.g., link prediction in hypergraphs (Category B.2).

## What the datasets cover

The Mission A tables in the report list submissions ranging from social and citation networks (Facebook, Twitch, Coauthor_CS) and the Open Graph Benchmark to molecular graph datasets such as QM9 and MoleculeNet, protein interaction data, analog circuits, water distribution networks, and neuroscience data. The A.1 winner brought ATLAS Top Tagging, a benchmark from particle physics, into the library, and the A.2 winner contributed Cornell Labeled Nodes Hypergraphs, a set of 8 hypergraph datasets. For a researcher looking for molecular graph datasets for topological deep learning, or for hypergraph benchmarks beyond the usual citation graphs, this is a useful starting list, since all of them sit behind one interface.

The count was 44 submissions from 30 teams, with most of the effort in Mission A (see the chart). Reviewers scored correctness, code quality, and documentation and tests, and not model accuracy. Since performance was not scored, what remains is reusable infrastructure.

## Why it matters for benchmarking

A shared interface makes comparisons fairer: the same model can now be run on many more graphs and higher-order datasets without custom data code. The organizers frame the next step as systematic benchmarking across the new datasets, since it is still unclear which topological domains and liftings, i.e., the conversions of a graph into a hypergraph or complex, fit which application. The on-disk loaders, in the organizers' view, make larger-scale workloads possible, which they connect to cross-domain pretraining and topological foundation models. The report names these directions as open and does not test them.
